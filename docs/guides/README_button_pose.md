## 位姿计算

1. YOLO 给出按钮类别和颜色图检测框。
2. 在检测框外围的环形区域采集 D2C 对齐深度，避免把凸起/凹陷按钮本身当作面板。
3. 对面板深度点做鲁棒平面拟合。
4. 令检测框中心像素射线与面板相交，得到 `p_camera`。
5. 面板法向朝向相机，记为 `normal_camera`；二者组成完整的
   `camera_to_button` 变换。

这比直接读取中心单像素深度稳定，也可以处理不正对相机的电梯面板。

## 输出变量

- `p_camera`：按钮表面中心在 RGB 相机坐标系下的 XYZ，单位米。
- `normal_camera`：按钮面板朝外法向在相机坐标系下的单位向量。
- `camera_to_button`：完整 4x4 按钮位姿。
- `p_tcp`、`p_base`：加 `--with-robot-state` 后输出，分别位于 TCP 和 base 坐标系。
- `tcp_to_button`、`base_to_button`：对应的完整 4x4 变换。

为兼容当前下游，报告暂时同步输出 `camera_to_marker`、`tcp_to_marker`、
`base_to_marker` 和 `marker_surface_xyz_m`；它们的数值分别等于相应的按钮变量。
