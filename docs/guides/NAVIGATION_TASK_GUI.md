## 模式与操作

- 不勾选“启用机械臂联动”：保持原单段导航测试，可选择点位，双次确认开启后点击“导航到所选点（3秒后）”。不自动启动机械臂。
- 勾选联动，选择“外呼→内呼→回桩”：执行本次新增完整流程。
- 勾选联动，选择“外呼→回桩（原流程）”：保留此前外呼按键完成后直接回桩的用法。

完整流程操作：

1. 按厂商要求在充电桩处完成初始化，确认地图为 `jxb_105.yaml`、定位与反馈正常。
2. 打开AGX GUI，填写实际当前楼层并点击“保存楼层”。
3. 勾选“启用机械臂联动”，选择“外呼→内呼→回桩”，连续两次点击“开启导航测试”。
4. 等待界面显示已启用，再在Android选择目标楼层并运行。目标楼层只输入这一次，执行期间楼层和流程选择冻结。
5. 等待自动执行：原位检查与3秒人员避让→liftout导航→上下行按钮闭环→归位复核→liftin导航→数字楼层按钮闭环→归位复核→厂商自动回桩。
6. 等待真实充电及连续停稳确认，GUI才显示整段完成。下一轮重新开启权限并接收新的Android请求。

上下行由GUI当前楼层与Android目标楼层比较决定。相同楼层不启动呼梯。当前是同地图布景测试，不检测电梯门，不自动将GUI当前楼层改成目标楼层。两个按键阶段都要等可靠熄灭才继续；按钮一直亮起时持续等待，不以超时或不确定当作完成。

Android电梯任务网关也监听 `.162:5005`，不能与本GUI同时打开。其他机械臂任务由共享互斥锁阻止并发。

## 暂停、停止与充电完成

停止和恢复对称处理 `/pause_robot_behavior`、`/robot_pause_to_relocate_behavior`、`/robot_pause_to_charging_behavior` 三个厂商接口。三个接口全部确认才显示恢复成功，且服务响应不能代替实际速度停稳反馈。

“停止任务”取消全部待发阶段、请求停止本GUI持有的机械臂任务并暂停底盘，迟到的成功回执不能继续内呼或回桩。关闭GUI也走停止流程。暂停不是删除厂家内部任务，不自动恢复未知旧任务。

“机械臂归位”先取消联动，等待当前机械臂任务退出、底盘暂停及停稳，再调用原安全归位并读编码器确认；不会归位后自动继续已取消的任务。“终止机械臂任务”不自动归位。

回桩继续走Android `command=1,value="back"` 对应的厂商充电管理流程，不用普通back坐标验证。放行要求本次序号Android确认、新充电指令9及服务成功记录，再解除三个暂停。arrive不表示充电完成；真实充电与充电信号均成立、反馈新鲜并连续停稳1秒，才显示完成。
