按钮 **开始任务：抓取→原位放置** 执行以下步骤：

1. 到 `config/bag_observation.json` 保存的纸袋观测位，使用手柄遥操的夹爪接口开爪。
2. 在观测位重新采集四张独立、同帧注册RGB-D与v3提手点，固定本次提手基座坐标。
3. 保持观测位工具朝向，到提手定位点，再沿工具前向在基座XY平面的投影**越过7厘米**。抓取目标高度与初始提手定位点相同；不是从前7厘米处接近，也不是夹爪开口7厘米。
4. 到达7厘米终点后闭爪，读取夹爪动作反馈，沿基座Z正方向垂直抬起5厘米，再经保存的中间关节位携袋返回观测位。
5. 沿携袋路径反向回到原闭爪位置上方5厘米，再将抬升轨迹反向执行，垂直下降5厘米回到原放置点，随后开爪，沿原插入/接近轨迹逆序退出至观测位。
6. 等纸袋后台退出后，自动调用语音GUI原有机械臂归位策略，实时编码器核验通过才报已归位。

本次观测位、提手定位点、前伸终点和出入轨迹均保存在当前任务报告。返回和放置复用同一任务轨迹，逆序时速度取反、加速度不变，不在近距重新识别、不从历史报告读取实际执行目标。新任务始终重新定位。闭爪后按用户最新要求增加5厘米竖直抬升，放置前对应下降5厘米；没有额外障碍绕行。

夹爪复用5015手柄桥：根据实时状态决定是否需要 `toggle_clamp` 开爪，闭爪使用确定目标的 `close_clamp`。沿用遥操电机目标0.0rad闭合、1.396rad全开；这些是电机角度，不是指间距离。开合回执不确定或超时不重发，不继续下一段。夹爪反馈可以确认执行过开合，不能确认纸袋已经夹住；完成状态明确区分“动作已执行”和实际夹持结果。

**保存当前为观测位** 只读取健康且静止的编码器；观测位与原有机械臂原点分开。**仅规划（不运动）** 不执行夹爪开合或机械臂运动；若当前不在观测位，只预检到观测位路径，实际定位须在观测位完成。

**停止机械臂** 中止当前动作链并取消待执行的自动归位；中止或失败后不自动开爪放置、不自动续跑。若已尝试闭爪，GUI提示可能仍夹持纸袋。**终止任务并返回原点** 先停止旧任务、等待后台退出与接口空闲、机械臂和底盘停稳，再调用既有归位程序。重复点击不重复排队；停止/关闭窗口会取消待归位；返程中也可停止。尚在执行的遥操夹爪动作沿用既有同步接口，后续动作须待其返回并再次检查停止状态。

主路径沿用TCP速度上限0.05m/s、关节比例0.25，每段不超过14.5秒。初始提手距TCP最多35厘米，前伸在其上额外增加7厘米；初始关节变化最多1rad、7厘米段最多0.6rad；IK位置误差≤1毫米、朝向误差≤0.5°，7厘米插入路径横向偏移≤3毫米。每段经过原5010桥MoveIt/关节限位预检，并检查起终点编码器；新抓放任务使用轨迹接口，不套用旧20毫米自动回撤的力控触碰段。

定位接受唯一高置信有效目标（检测≥0.65、关键点≥0.5），同帧注册深度640×360，中心点深度有效、5×5邻域有效率≥80%且跨度≤10毫米，四帧XYZ偏离中位数≤3毫米、像素≤3px。固定目标后不补偿袋子移动。按用户要求不启用纸袋新增点云净空或深度残差障碍判定；深度用于初始定位和数据健康，原桥内部校验保持。
